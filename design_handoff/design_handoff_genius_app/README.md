# Genius — 视频创作平台 UI 设计交接（给实现方）

原型文件：`Genius App.dc.html`（浏览器直接打开，五个视图 + 全部交互状态可点）。
本包是**设计规格**，不是生产代码。请在你们的技术栈里重建，取值以本文档与原型为准。

---

## 0. 一句话结构

左侧固定导航（主页 / 创作 / 智能体 / 画布 / 订阅）＋ 右侧内容区（56px 顶栏 + 滚动主体）。
创作面板是**悬浮层**：它是滚动容器的兄弟节点，不占页面空间、不随滚动移动，始终贴在内容区底部。

```
<shell flex row>
  <aside 212px>            品牌 + 5 项导航 + 页脚
  <column flex:1 position:relative>
    <header 56px>          视图标题 · 右侧账户簇
    <main flex:1 overflow:auto>   ← 只有这里滚动
    <bar / composer / modal>      ← position:absolute，锚在 column，不随 main 滚动
  </column>
</shell>
```

**关键点：** 悬浮框绝不能放进滚动容器内。放进去就会随内容滚走。它必须是滚动容器的**兄弟**（或用 sticky/fixed），且外层不加遮罩渐变、内容区不预留 padding-bottom。

## 6. 画布（图 2、26–37）

**空态**：两张微旋转的卡片（-13° / 9°）+「右键」胶囊 + 标题「在画布上放下第一个节点」+ 副标题 + 四个入口按钮（生图 / 故事视频 / 三视图 / 九宫格）。

**场景层**：作者坐标系 900×620，外层滚动容器 `padding:8px 8px 8px 100px`（**必须给左侧工具栏留出空间，否则浮动栏压住节点**），内层 `transform:scale(fit × zoom)`，`transform-origin:0 0`。`fit = clamp(0.4, min((W-108)/900,(H-72)/620), 1.4)`，缩放读数显示 `round(fit×zoom)%`（必须是真实生效值）。

**节点**：标签行（图标 + 名称，13px 弱色）+ 内容体（圆角 10、`#141417`、inset 描边）。连线用一层 SVG 贝塞尔（`rgba(255,255,255,.22)`，1.2px），端点坐标取自节点实际位置。

**交互链：**
1. 悬停文本节点（图 27）→ 左右各出 18px ⊕ 手柄。
2. 点 ⊕（或左栏白色 +）→ 类型菜单（图 28）：文本 / 图片 / 视频 / 音频 / 分镜表。
3. 选「文本」→ 新增「文本 3」节点 + 顶部富文本条（H1 H2 H3 ¶ B I A 1. • —，当前项高亮）+ 下方提示词面板：图标行（文本 / ＋ / 工具箱，工具箱 hover 提示「从工具箱选择参考」）、输入区、底部 模型芯片 + 字数 `n/5000` + ⚡成本 + 渐变发送。
4. 点模型芯片（图 29）→ 上弹 330 宽「模型」列表：Claude（擅长复杂推理、长上下文理解和高质量写作）/ Seed（中文理解能力强…）/ Qwen（平衡的通用能力…）。

6. 应用 → 画布落下 `Upload a picture` + `Output Results` 两个节点并连线（图 31–32）；**鼠标移入结果视频播放、移出停止**（原型用 hover 进度条模拟，实现时用真实 `<video>` 的 play/pause）。

## 9. 实现注意（踩过的坑）

1. **悬浮面板必须在滚动容器之外**，否则滚动时跟着走；同时内容区不要为它预留 padding，遮罩渐变也不要（面板本身用不透明底 + 强阴影即可）。
2. 顶栏右侧簇不能 `overflow:hidden`，所有文字 `nowrap`；视图专属操作放到该视图自己的浮层里。
3. 画布场景用「作者坐标 + 统一缩放」，缩放读数要显示真实生效百分比；节点字号按缩放后的可读性反推（正文 11、标签 13）。
4. 画布左侧浮动工具栏与场景层同容器时，用容器 padding 把场景推开，别靠调节点坐标。
5. 素材弹窗、模型弹层等层级：模态 z-index 高于面板；弹层用 `position:absolute` 锚在触发元素的 `position:relative` 父级上。
