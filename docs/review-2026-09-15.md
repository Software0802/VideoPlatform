## 4. 分维度评估

### 4.1 主路径（强，保护它）

mock 下全部闭环走通且行为一致：5s 文生视频 1.8 秒出片、`<video>` 可播可下载、扣积分与估价一致；连点两次「创作」只发 1 个 POST（客户端 `busy` + 幂等 key）；两条 SSE 全部中断时轮询照样把任务推到完成；`POST /api/jobs` 注入 500 / 网络失败后去掉注入同一按钮直接成功；30s 任务中刷新 / 后退 / 前进 / 第二标签页都显示同一进度、双标签最终积分一致；服务重启 4 秒内不刷新页面即变「失败」且退款到账，`job.json` 状态与账户「在途预留 0」一致。画布：右键四类节点、连线、防抖落盘、刷新保留、报价冻结、审批驳回退回、复用报价 ¥0.00、双标签冲突层二选一。订阅：四档真实人民币价、年付 = 12× 不打折、402 / 409 各有正确文案。分享页未登录新 context 桌面与手机都能播，删除后 404。

### 4.2 失败反馈（中）

模式是「后端把事做对了，前端没把话说清」：上传坏文件（U-01）、服务不可达（U-05）、重启后（U-06）、限流（B-04）、余额不足（U-03b）、部分成功（C-24）、有任务在跑（U-14）——每一条后端的状态与钱都是对的，用户看到的要么是空白、要么是运维文案、要么是指向不存在动作的提示。这些是本轮最集中的一类问题，也是最便宜的一批修法（多数是文案与一个错误行）。

### 4.3 移动端与可访问性（中-）

不横向溢出、焦点可见、Esc 收层、reduced-motion 归零这些基础项都做了。缺的是第二层：弹层焦点管理（U-07）、画布在手机上的可操作性（U-02）、被 `globals.css` 盖掉的贴边规则（U-13）、触控热区（U-15）、对比度令牌（U-22）、方向键（C-17）、`aria-live` 粒度（C-05）。这些都不影响鼠标用户，但决定了键盘 / 读屏 / 手机用户能不能用。

### 4.4 后端健壮性（良）

上轮评「强」的资金与恢复本轮从用户侧再看一遍仍然成立：`uncertain_submit` 的 `reconcile/resume` 出路、取消在 `persisting` 阶段拒绝（三输理由写明）、留存只写 `artifactsPurgedAt`、配额与留存共用结算口径、进度 `Math.max` 永不回退（90 → 100，不存在 99）、`sessionEpoch` 让停用 / 改密 / 退出全部设备立即生效、验收暴露的 6 类上游问题防线全在。缺口集中在智能体轮次（B-07 / B-09 无任何服务端恢复）与留存零预告（B-05）。

### 4.5 门禁与工程（中）

e2e 在 Linux 首次跑就 43/43 绿，说明套件本身健康。但三件事让本地门禁不可信：过期 dev 类型缓存假红（B-01）、relay 单测偶发红（B-03）、mock 预览配置起不来（B-02）。B-01 与 B-03 都是「本地红、CI 绿」或「随机红」，是最容易让人养成「再跑一遍」习惯的形态。

## 5. 不要被「优化」掉的东西

- 连点「创作」只建一条、幂等 key 在提示词 / 任何选项改动时作废、提交全成功才清空（`ComposerProvider.tsx:177-181`、15 处 `dropKey()`）。
- `useEvents.ts:78-87` 的 `close()` + 1/2/4/8/15s 退避与 `visibilitychange` 补拉——`useJobLive` 应向它对齐，而不是反过来。
- `cancel.ts:32` 在 `persisting` / 已有 `localOutputPath` 时拒绝取消。
- `src/lib/i18n/error-codes.test.ts` 扫四类出口做字典回归；`errorText.ts:32-36` 认不出的码回落 `common.err.unknown` + 请求号。
- 分享页零客户端 JS、`generateMetadata` 随 locale、坏 token 一律 `notFound()`。
- `CanvasView.tsx:93-96/224-250` 保存串行链 + `expectedRevision`；409 二选一不静默覆盖。
- `quota.ts` 的 `BLAMELESS_FAILURE_CODES`（上游挂了不算用户头上）。
